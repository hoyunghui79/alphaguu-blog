阿發（住在紐西蘭的黃金獵犬）的部落格內容工作區，網站：alphaguu.com（WordPress）。

## 資料夾
- `content/posts/`：文章（Markdown）
- `static/images/`：圖片
- `docs/`：阿發人設、專欄規則、寫作規則
- `CLAUDE.md`：給 AI 的專案說明

## 流程
1. 在分支上寫文章 → 2. 開 Pull Request → 3. Patricia 檢查後 Merge → 4. 手動貼到 WordPress 發佈。
