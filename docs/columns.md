# 專欄規則

每篇文章的 `categories` 只填一個主專欄，名稱要和下表完全一致。「故事：資訊」是建議比例。

| 專欄 | 內容 | 故事：資訊 | 結構重點 |
|---|---|---|---|
| 阿發狗故事 | 真實的狗狗故事（工作犬、輔助犬、傳奇犬） | 7:3 | 阿發日常開場 → 過渡到那隻狗 → 時間線敘事 → 阿發感想。事實要有出處，人狗名字、年份、數字要核對 |
| 狗命人生 | 阿發的日常、養狗經驗、活動 | 6:4 | 以體驗為主；涉及法規、費用、疫苗時必須標來源與查證日期 |
| 阿發帶你趴趴走 | 紐西蘭景點導覽、親子景點 | 5:5 | 開場故事 → 景點亮點 → **實用資訊區**（地址、開放時間、票價、交通，皆標「查證日期」）→ 阿發點評 |
| 阿發旅遊資訊台 | 旅遊實用資訊（自駕、交通、緊急狀況） | 3:7 | 條列與步驟為主，阿發負責開場和點評；不確定的資訊寫「待確認」 |
| Kiwi好物選品室 | 紐西蘭伴手禮、零食、好物推薦 | 4:6 | 每項含：是什麼、為什麼推薦、哪裡買。有商品連結時見下方「商業揭露」 |
| 阿發封面獸 | 紐西蘭特有動物（訪談對話體） | 6:4 | 阿發與動物嘉賓對話（例：Kākāpō、Kiwi、Tuatara）。動物習性、保育狀態、數量要查證，不可為了笑點亂編科學事實 |
| 阿發黃金食譜 | 阿發負責**發表媽媽的食譜**：人吃的台灣料理與紐西蘭料理（不是狗食譜） | 4:6 | 阿發插畫 + 真實食物照片。結構見下方「阿發黃金食譜：結構與規則」 |

## 商業揭露（選品室與任何有商品連結的文章）
- 有業配、聯盟連結、贊助或免費樣品時，文章開頭要明確標示。
- 之後接上 Shopify 商品區塊時，商品區塊要與內文清楚區分。
- 不可捏造使用心得或評價：沒有實際試過的商品，不寫「阿發吃過」。

## 阿發黃金食譜：結構與規則
**角色分工**：阿發是發表人（插畫）；食譜的創作者是**媽媽**，一位每天認真研發新料理、像廚房科學家的人。媽媽的設定見 `persona-ah-fa.md`。

**建議結構**
1. **阿發開場**：今天媽媽又在廚房做實驗（可用聞到燒焦味、廚房的動靜當開場）
2. **實驗紀錄**：媽媽這次想解決什麼問題、試了什麼、哪裡失敗、怎麼調整（阿發用旁觀者的口吻轉述）
3. **食譜**：食材、份量、步驟、時間、火候
4. **阿發評審**：阿發在旁邊的反應（流口水、盯著看、被爸爸或媽媽趕出廚房），**不真的吃人的食物**
5. **失敗小教室**（選填）：這次燒焦或失敗的地方，怎麼避免

**規則**
- **食譜內容由 Patricia 提供**（食材、克數、時間、火候）。AI 只負責整理格式並用阿發的口吻改寫，**不可自行更改份量，也不可創造沒有測試過的食譜**。
- 資料不完整（例如沒寫份量或火候）就標「待補」，不要猜。
- 台灣料理要註明在紐西蘭可買到的食材或替代品。
- 食譜是給人吃的。阿發在文中想吃時，要寫「這道菜不能給狗吃」。
- 提到對狗有害的食材（洋蔥、大蒜、巧克力、葡萄與葡萄乾、木糖醇、夏威夷豆等）時，加一句提醒。
- 涉及食品安全的步驟（生肉、雞蛋、加熱溫度與時間）要寫清楚，不能為了搞笑省略。
