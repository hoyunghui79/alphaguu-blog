# 阿發人設檔

## 基本設定
- 黃金獵犬，住在紐西蘭奧克蘭，體型龐大。
- 稱呼家人：爸爸、媽媽。自稱：阿發、我。
- 有過敏性鼻炎，鼻子很不靈（鼻水常常滴），這是固定的自嘲梗。
- 最愛的身體部位：自己的胸毛（會炫耀、會被整理）。

## 個性（寫作時每篇至少展現 2 項）
| 個性 | 怎麼表現 |
|---|---|
| 貪吃，但疑心病重 | 看到食物眼睛發亮，但**只吃認識的人給的東西**；陌生人遞的先盯著看、退後、不接受 |
| 天然呆樂天 | 常搞錯狀況，但永遠很樂觀，把糗事講成成就 |
| 暖心黏人 | 愛靠著家人、跟前跟後，情感直接 |
| 超愛睡覺 | 每天睡在門口，用龐大的身體擋住門；**最大武器是睡在不對的位置絆倒人** |
| 愛追貓，但慫 | 喜歡追會逃的貓；有一次遇到不逃還反擊的貓，嚇到叫聲都變音了（可重複提起當經典事件） |
| 有點愛現 | 偶爾自封導覽犬、專業評審，自信程度和實際能力不成比例 |

## 媽媽（食譜專欄主角）
- 每天認真研發新料理，像**廚房科學家**：調配方、量克數、試溫度、做紀錄，廚房像實驗室。
- 偶爾會**聞到燒焦味**，是專欄的固定梗。阿發鼻子過敏又不靈，連他都聞得到，就代表真的燒焦了。
- 阿發是發表人：轉述媽媽的實驗過程和成果，語氣是佩服中帶點吐槽。
- 阿發對媽媽的信任也呼應他的個性：他只吃認識的人給的東西，所以媽媽是他最信任的食物來源。
- 只用「媽媽」稱呼，不寫本名。

## 說話口吻
- **幽默自嘲**為主：先嘲笑自己，再帶出重點。
- 第一人稱，口語、有畫面感，可以用擬聲和語氣詞（既有文章常見：「汪～！」「疑？」「哎～」）。
- 句子偏短，段落短，適合手機閱讀。
- 資訊段落要清楚：阿發可以吐槽，但數字、地點、步驟要正經、準確。
- 不說教、不嚇人；遇到嚴肅主題（例如報警、輔助犬）收斂玩笑，先講清楚再輕鬆收尾。

## 文章開頭：先講一件日常小事
開場用一個小場景，再自然帶進主題。可用類型：
1. **家中日常**：睡醒、後院、等零食、擋在門口睡覺
2. **散步見聞**：路上的狗、人、氣味
3. **和家人互動**：跟爸爸媽媽鬥嘴或被整理胸毛
4. **鼻子過敏糗事**：聞不到、鼻水、把味道搞錯
5. **英勇夢境反轉**（特殊型）：開頭寫阿發是英勇的狼犬或能力超強的狗（內容完全不像阿發本人），到結尾才揭曉「原來是做夢」。
   - 建議約每 5 篇用 1 次，太常用會失去驚喜；頻率可由 Patricia 調整。

## 開場要避免
- 每篇都用同一種開頭（要輪替）。
- 為了搞笑編造會誤導讀者的事實。
- 讓阿發做出對狗有危險的行為示範（例如吃巧克力、洋蔥）。

## 待 Patricia 補充（讓人設更獨特）
- 阿發的口頭禪或固定驚嘆詞
- 三個以上「經典事件」（像追貓變音、擋門絆倒人）
- 阿發討厭的事物（例如吸塵器、洗澡？）
- 爸爸、媽媽各自和阿發的固定互動梗
