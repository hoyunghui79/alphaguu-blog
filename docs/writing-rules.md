# 寫作與檔案規則

## 寫文章的流程
1. 確認**專欄**和**主題**（缺資訊就先問 Patricia，一次問一個問題）。
2. 需要事實的主題先查資料，記下來源網址與查證日期。
3. 依 `persona-ah-fa.md` 選一種開場，再依 `columns.md` 的結構寫。
4. 建立分支，檔案放 `content/posts/`，提交後開 Pull Request。
5. PR 說明列出：專欄、字數、待確認事項、需要 Patricia 補的照片。

## 檔名
`YYYY-MM-DD-英文小寫連字號.md`，例如 `2026-10-05-auckland-museum.md`。

## Front matter（檔頭）
```yaml
---
title: "文章標題"
date: 2026-10-05
draft: true
categories: ["阿發帶你趴趴走"]
tags: ["奧克蘭", "親子景點"]
summary: "一到兩句摘要（給搜尋與分享用）"
---
```
- `draft: true` 由 Patricia 發佈時才改。
- 開頭一定要有 `---` 而且每個欄位只寫一次。

## 內文格式
- 標題用 `##`、`###`，不用 `#`（`#` 留給文章標題）。
- 每段 2 到 4 句；重點資訊用條列或表格。
- 旅遊與景點文章要有「實用資訊」區，並標「查證日期：YYYY-MM-DD」。
- 結尾由阿發收尾，可以帶一句下一篇預告。

## 事實查核
- 價格、時間、地址、法規、電話：必須有來源，並在文章或 PR 說明裡附上網址。
- 查不到或來源互相矛盾：寫「待確認」，並列在 PR 說明。
- 動物與歷史內容：以官方或權威來源為準（例如保育單位、政府網站）。
- 涉及狗狗健康、飲食：只講一般常識，並建議詢問獸醫，不提供診斷。

## 圖片
- 現有文章的圖片仍連到 `https://alphaguu.com/wp-content/uploads/...`。
- 新文章不編造網址；需要圖片處寫 `![說明](TODO-圖片)`，並在 PR 說明列出「建議拍攝清單」。

## 不要提交
密碼、API key、`.env`、WordPress 匯出 `.xml`、留言者資料、任何家人個資。
